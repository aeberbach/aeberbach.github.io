Well, Publish by Sundell got me this far. No complaints but doesn't seem to have been updated recently (even longer ago than my last post here). And I intend writing some more in future, so time for a change.

I'm trying out Zola and so far it seems pretty good. It's fast, easy to install, easy to configure, easy to preview pages locally. And it's written in Rust apparently, one of those things I should look at one of these days. 

One gotcha is the documentation mentions shortcodes, which are no longer a thing! Instead they are replaced by Tera components. Here's the component that resizes an image to show the inline thumb version, linking to the full-size version if clicked. A supplied caption is displayed.

{% raw %}
<pre>
{% component image_thumb(path: string, caption: string) -%}
{% set thumb = resize_image(path=path, width=600, height=10, op="fit_width") %}
{% set image = resize_image(path=path, width=5000, height=5000, op="fit") %}
&lt;figure&gt;
    &lt;a href="{{ image.url }}"&gt;&lt;img src="{{ thumb.url }}" alt="{{ caption }}"/&gt;&lt;/a&gt;
    {% if caption %}&lt;figcaption&gt;{{ caption }}&lt;/figcaption&gt;{% endif %}
&lt;/figure&gt;
{% endcomponent %}
</pre>
{% endraw %}

And here is how it is used in the markdown files:

{% raw %}
<pre>
{{&lt;image_thumb path="/images/moose.jpg" caption="A majestic moose." /&gt;}}
</pre>
{% endraw %}

It's not so hard and makes for much cleaner source. And this needs improving too since some images are higher than they are wide and it should handle that and not enlarge images when trying to create a thumb. All in good time.

<p>In the conversion process I tried out using Copilot in Visual Studio Code to reformat the HTML, which after a couple of engine changes had some stuff that could be fixed or just plain removed. I wasn't all that impressed. It was quicker than doing it manually I guess? But too much "shall I run this incredibly complicated awk, grep, perl command?"  - what am I going to do, spend 20 minutes studying regex before approving? No, make a backup and see what happens. And then it takes several minutes to run, and then it isn't always right, I had several rollbacks. Sometimes it just removed the image tags altogether.
